A complete runnable recreation of the uploaded video using HTML, CSS and vanilla JavaScript.

## Five animations
1. **Typewriter Text** — characters appear progressively with a blinking caret.
2. **Fade In Up** — text fades in while moving upward.
3. **Glow Pulse** — cyan neon text glow pulses.
4. **Bounce Letters** — each letter bounces with a staggered delay.
5. **Wave Text** — characters move in a repeating wave.

## Features
- Dark navy preview cards with orange outlines
- Live animation previews
- CSS snippets shown under each example
- Copy CSS buttons
- Responsive layout
- Reduced-motion support
- No external dependencies

## Run locally
```bash
python -m http.server 8000
```
Open http://localhost:8000

## Files
- `index.html` — gallery markup and previews
- `style.css` — styling and keyframe animations
- `script.js` — copy buttons and wave-letter setup

## Extraction note
The video displays the rendered examples and portions of their CSS, not every line of the original source. This project recreates the visible effects and layout as a complete runnable implementation; it is not a verbatim dump of unseen source code.
