Typewriter Animation

Typewriter Text

Text appears one character at a time, like a classic typewriter.

.typewriter {
  overflow: hidden;
  white-space: nowrap;
  border-right: 2px solid #60a5fa;
  animation: typing 2.5s steps(7) infinite,
             blink .7s step-end infinite;
}
@keyframes typing {
  from { width: 0; }
  to { width: 7ch; }
}
@keyframes blink {
  50% { border-color: transparent; }
}

Fade Up

Fade Up Motion

Fade In Up

The text smoothly rises into place while fading in.

.fade-up {
  animation: fadeUp 2s ease-in-out infinite;
}
@keyframes fadeUp {
  0% {
    opacity: 0;
    transform: translateY(30px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}

Glow Text

Neon Glow Pulse

Glow Pulse

A neon cyan glow pulses around the text for a luminous effect.

.glow {
  color: #00eaff;
  text-shadow: 0 0 5px #00eaff,
               0 0 10px #00eaff,
               0 0 20px #00eaff;
  animation: glowPulse 1.5s ease-in-out infinite alternate;
}
@keyframes glowPulse {
  from { text-shadow: 0 0 5px #00eaff; }
  to {
    text-shadow: 0 0 10px #00eaff,
                 0 0 25px #00eaff,
                 0 0 40px #00eaff;
  }
}

BOUNCE

Letter Bounce Animation

Bounce Letters

Each letter bounces with a small delay, creating a wave-like rhythm.

.bounce span {
  display: inline-block;
  animation: bounce 1s ease-in-out infinite;
}
.bounce span:nth-child(2) { animation-delay: .1s; }
.bounce span:nth-child(3) { animation-delay: .2s; }
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-14px); }
}

Wave Text

Letters move up and down in sequence to create a flowing wave.

.wave span {

  animation: wave 1.2s ease-in-out infinite;
}
@keyframes wave {
